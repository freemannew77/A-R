# Alder & Rowe website

A static, multi-page website built with HTML, CSS, and JavaScript. It can be hosted on GitHub Pages without a build step or package installation.

## Pages

- `index.html` — home
- `about.html` — firm background and approach
- `services.html` — practice descriptions
- `team.html` — attorney profiles
- `insights.html` — educational articles
- `contact.html` — contact details and next steps

## Publish with GitHub Pages

1. Upload the contents of this folder to the root of a GitHub repository (or configure Pages to use this folder as the publishing source).
2. In the repository settings, open **Pages** and select the branch and folder containing `index.html`.
3. Save the settings. GitHub Pages will publish the site from those static files.

All page links use relative paths, so the site works from a GitHub Pages project URL as well as a custom domain.

## Before publishing

Replace the fictional firm name, attorney bios, location, phone number, email addresses, office hours, and legal notices with verified details. The `.example` email domain is reserved for examples and will not receive email. Add your own privacy and accessibility statements and confirm bar advertising rules for the jurisdictions where the firm practices.
